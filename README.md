# pluton-syntax theme

Anna's syntax theme designed for C and Zig, the goal is to highlight the most important parts of the code, and make comments easily viewable while sticking to the usual styling of green strings, purple keywords, and the like.

NOTE: while light mode is an option it is very much a work in progress currently

These screenshot is using Iosevka, but you may use whichever font you would like
